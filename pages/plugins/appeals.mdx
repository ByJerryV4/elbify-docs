<Info>
  Before reading, please toggle the "Appeals" plugin **on** in the **Plugins** menu on the dashboard. You can configure what types can be appealed on the dashboard.

  **The Appeal form must be live in the "Forms" core section and there must be at least one appealable moderation type set on the dashboard in order for this plugin to work as intended.**
</Info>

## Submitting an Appeal

Submitting an appeal for a moderation you received in a server is really simple and can be done on the website **Forms** _(insert link here)._ Select the server you want to appeal the moderation in and complete the form.

**Servers may have their own form configurations.** Always check information with the server if you're unsure - Elbify Staff **cannot** assist you with server form inquiries.

---

Once the form is filled out and looks correct, submit the appeal. If the plugin is enabled, it'll be sent to a private staff channel of the server where the staff will thoroughly review your appeal.

You **cannot** edit or delete appeals once they are submitted. Before submitting, ensure everything is correct.
